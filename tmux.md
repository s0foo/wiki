# Session
- Rename session: `C-b : rename-session <session_name>`

# Windows
- Create a new window: `C-b c`
- Rename the current window: `C-b ,`
- Kill the current window: `C-b &`
- Move window: `C-b . <window_index>`
- Move to last window: `C-b l`
- Move to next window in the list: `C-b n`
- Move to previous window in the list: `C-b p`
- Swap two windows: `C-b : swap-window -s <source_window_index> -t <target_window_index>`

# Pane
- Previous pane: `C-b ;`
- Resize: `C-b C-<arrow>`

# General
- Display help: `C-b ?`
- Scroll: `C-b : set -g mouse on`
- Enable vi mode: `C-b [`
